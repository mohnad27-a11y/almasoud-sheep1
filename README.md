# شركة المسعود للأغنام — النسخة الأولية MVP

مقر الشركة: قرية الفقهاء – جازان
نطاق التوصيل: صبيا شمالاً، صامطة جنوباً، أبو عريش شرقاً
التوصيل: مجاني حتى 20 كم، وبعدها 35 ريال

## الأقسام
بلدي، حري، تيوس، طليان، رخال

## المزايا الأساسية
- رقم فريد + QR لكل رأس
- عروض يومية وخصم الإدارة وكوبونات
- «ميزانيتك كم؟»
- «اشترِ بثقة»
- تنبيه عودة الرأس للتوفر
- مشاركة موقع العميل وGPS
- شراء الآن واستلم من الفرع
- السلة والطلبات وتتبع الطلب
- حساب العميل والمفضلة والولاء والإحالات
- المناسبات والطلبات الكبيرة
- واجهة للسائق
- لوحة إدارة وتقارير ومخزون
- الدفع الإلكتروني + Tabby + Tamara
- كاش وشبكة عند الاستلام

## محذوف
المزاد الإلكتروني وسوق المربين.

> هذه نسخة أولية للواجهة والمنطق الأساسي. الربط الإنتاجي مع مزودي الدفع والخرائط والإشعارات يحتاج حسابات ومفاتيح API وWebhooks.
